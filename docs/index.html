A LITTLE GUIDE

게임은 이렇게.

  1. 장르와 문제 수를 고르고 게임 시작하기를 누르세요. 선택한 수보다 문제가 적으면 있는 만큼 출제합니다.
  2. 이미지를 보고 참가자들이 대사를 맞힙니다. 정답 공개를 눌러 대사와 작품명을 확인하세요.
  3. 문제 보관함의 문제 관리에서 장면을 추가·수정·삭제할 수 있습니다. CSV/JSON으로 여러 문제를 한 번에 가져올 수도 있어요.
