      A LITTLE GUIDE

      게임은 이렇게.

      1. 카테고리와 문제 수를 고르고 게임 시작하기를 누르세요. 선택한 수보다 문제가 적으면 있는 만큼 출제합니다.
      2. 이미지를 보고 참가자들이 대사를 맞힙니다. 어려우면 힌트로 작품 제목을 공개하고, 정답 공개로 대사를 확인하세요.
      3. 게임을 마치거나 게임 종료를 누르면, 실제로 본 문제를 플레이 기록에서 회차별로 확인할 수 있어요. 이 브라우저에 최근 10회차를 보관합니다. 회차를 선택하고 회차 이미지 내보내기를 누르면 해당 이미지들을 ZIP으로 받아요.
      4. 문제 보관함의 이미지 전체 내보내기에서 편집용 이미지를 ZIP으로 받으세요. 파일명은 작품명 - 대사이며, 검색·분류와 관계없이 전체 이미지를 포함합니다.
      5. 문제 보관함의 문제 관리에서 장면을 추가·수정·삭제할 수 있습니다. CSV/JSON으로 여러 문제를 한 번에 가져올 수도 있어요.
